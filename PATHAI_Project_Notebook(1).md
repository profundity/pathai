# PATHAI Project Notebook

## Purpose
PATHAI is a research platform for extracting causal biological knowledge from biomedical literature.

## Accomplishments
- Chunking pipeline
- mentions.jsonl extraction
- atoms.jsonl generation
- GPT routing (4o-mini -> 4.1 escalation)
- Validation heuristics
- Bridging concept
- Human-readable inspection utilities

## Pipeline
Seed papers -> Chunking -> Mentions -> Atoms -> Bridge -> Knowledge Graph

## Major Milestones
- Built strict JSON schemas.
- Added routing metadata.
- Added span validation.
- Added confidence heuristics.
- Added atom generation preserving evidence.
