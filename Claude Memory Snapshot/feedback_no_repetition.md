User feedback, verbatim: "Tell me facts and reasoning but don't keep repeating the same stuff using different words. It is exhausting."

**Why:** responses have tended to make one point, then restate it in a slightly different phrasing for emphasis, then restate again as a "plain summary" — three passes at one idea. This reads as padding, not thoroughness, and is tiring to read. Related to [[feedback-soften-tone]] (register) but distinct: this is about density/repetition, not warmth.

**How to apply:** state each fact or point once. Cut restatements, "in other words," and closing summaries that just repeat what was already said. If a point needs elaboration, add new information, not a rephrasing of the same information.

**Reinforced later, more specifically on structure:** "Please use less verbose language. Be concise but not leaving out details. Try not to repeat things in 2 different ways unless that clarity is essential." Applies especially to multi-layer explanations (e.g. literal/context/relevance breakdowns) — don't restate the same fact under each layer heading; each layer should add something the others don't. Default to shorter sentences and fewer setup clauses, without cutting substantive content — the target is density, not brevity for its own sake.
